# Crédits, sources et licences des images

Ce dossier documente la **provenance** et les **conditions de réutilisation** de
chaque image. La règle suivie est stricte : **seules des images librement
réutilisables** (domaine public / Creative Commons / Licence ouverte Etalab) sont
**téléchargées** dans le dépôt. Les documents **sous droits réservés** (clichés de
laboratoire, photothèques restreintes) ne sont **pas redistribués** : ils sont
**liés** ci-dessous, avec attribution, pour consultation.
